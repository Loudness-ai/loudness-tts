# Contributing

Issues and pull requests are welcome: bug reports with the exact text, voice id and `local-tts doctor --json` output help most.

```sh
cd python
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev,timings]"
local-tts download en_US-clean100-medium      # lets the synthesis tests run
pytest -q
```

Text preparation rules live in `python/src/local_tts/textprep.py` (Apache-2.0); add a test in
`tests/test_textprep.py` with every rule change. The voice catalogue is generated by `scripts/build_catalog.py` from
the published voice study; do not edit `voices.json` by hand. By contributing you agree that your contribution is
licensed under the project's licences (GPL-3.0-or-later; Apache-2.0 for `textprep.py`).
